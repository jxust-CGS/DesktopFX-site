# DesktopFX 桌面特效

> 给 Windows 桌面加一层会呼吸的天气。

**DesktopFX** 是一个纯 Python 编写的 Windows 桌面特效程序。它用 `ctypes` 直接调用 Win32 的
`UpdateLayeredWindow`，在整个虚拟屏幕（含多显示器）上盖一层半透明覆盖层，实现 13 种特效。

本仓库是它的**产品介绍页**（GitHub Pages 托管），不是源码仓库。
源码在 → **[jxust-CGS/DesktopFX](https://github.com/jxust-CGS/DesktopFX)**

---

## 13 种特效

| 分类 | 特效 |
| :--- | :--- |
| **全屏特效** | 下雨 / 下雪 / 落樱 / 流星雨 |
| **鼠标拖动特效** | 聚光灯 / 颜料盘 / 宠物跟随 / 鼠标涟漪 / 真实水波 |
| **鼠标点击特效** | 点击表情 / 点击文字 |
| **鼠标点击音效** | 点击音效（不画像素，纯听觉） |
| **其他特效** | 窗口水波 |

同类默认**互斥**（新开一个会自动关掉另一个），可在「其他设置」里改成「允许多开」，
就能雨雪同屏、聚光灯 + 水波一起上。

## 几个不一样的实现

- **透明覆盖层**：`WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_TOPMOST`，
  鼠标事件完全穿透，不拦截任何点击。像素走预乘 alpha，不需要任何 GUI 框架。
- **真实水波**：高度场 + 速度场双缓冲的二维波动方程。波会向外传播、相互干涉、
  撞到屏幕边缘反射 —— 一次点击的涟漪要好几秒才传遍屏幕。
- **窗口水波**：把桌面上的窗口当成水面上的活塞。移动时前缘推水、后缘留空腔；
  **静止的窗口绝对零注入** —— 泡着不动的石头不搅水。
- **宠物跟随**：形象与动画完全由代码绘制，不引入任何图片资源。跟随走**临界阻尼弹簧**，
  手感不随帧率变。
- **流星雨**：轨迹按间距采样成一串同半径圆盘盖章，圆盘核内留一段平坦区，
  否则相邻圆盘的中点亮度只有一半，彗尾会串成珠子。
- **置顶保活**：每帧自检是否被第三方置顶窗盖住，链签名短路让这项检查约 0.7µs。

## 运行

Windows 10 / 11，依赖只有 `numpy`（渲染）和 `Pillow`（界面抗锯齿）。

```bash
git clone https://github.com/jxust-CGS/DesktopFX.git
cd DesktopFX
python desktop_fx.py
```

或直接下载 [Releases](https://github.com/jxust-CGS/DesktopFX/releases) 里的打包版。

## 关于本页

- 视频是**用项目自己的渲染引擎离线逐帧生成**的，与桌面上跑的是同一份代码、同一份参数。
- 画面里的光标会真的移动、真的按下 —— 聚光灯跟着光标亮、颜料被它搅动、
  小猫沿它划过的路线跟上来、爱心在它点下的位置炸开。
